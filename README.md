# Интерактивная 3D-модель планеты Земля

Реалистичная интерактивная 3D-модель Земли (Three.js) с перетаскиванием/масштабированием, метками городов и достопримечательностей, карточками с фото и описанием, переходом в Google Maps по двойному клику.

## Запуск

```bash
npm install
npm run dev
```

Откройте http://localhost:5173

Сборка продакшена:

```bash
npm run build
npm run preview
```

## Возможности
- Реалистичные текстуры Земли (день/ночь, нормали/блик, облака, атмосфера, звёзды).
- Вращение, зум, инерция (OrbitControls).
- Метки ~64 городов и ~28 достопримечательностей.
- Один клик — карточка места с фото и описанием (Wikipedia API, на выбранном языке).
- Двойной клик — открытие локации в Google Maps.
- 4 языка: русский, английский, французский, китайский; переключатель в правом верхнем углу.

## Технологии
Vite, Three.js, Wikipedia REST API.
